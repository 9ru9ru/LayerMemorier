# LayerMemorier 독립 가시성 + 패널 미리보기 spec

작성 2026-10-02. 기반: `Plans/V 20260915_LayerMemorier_spec.md`(이하 "기존 spec"), `Plans/20261001_LayerMemorier_combos_spec.md`(이하 "조합 spec"), `Plans/20261002_LayerMemorier_export_spec.md`(이하 "내보내기 spec"). 이 문서는 바뀌는 부분만 적는다.

## 0. 한 줄 요약

내보내기·미리보기 결과를 PSD의 눈 상태와 무관하게 조합 체크만으로 정한다 (체크한 레이어 + 그 부모 그룹만 켜고 나머지는 전부 끔). 그룹 체크박스 Ctrl+클릭으로 하위 전체를 한 번에 넣고 뺀다. 레이어 탭 왼쪽에 지금 고른 조합을 포토샵이 그린 그림으로 보여 주는 "패널 미리보기"를 토글로 더한다. 배리에이션이 0개일 때 이유를 보여 준다 (이슈 #1).

## 1. 배경

0.3.0을 실제 PSB로 써 본 사용자 피드백 (2026-10-02):

- "레이어 체크가 제대로 안 먹는다. PSD에 보이는 게 거의 그대로 출력된다." 원인: 조합 spec §5.2는 어느 조합에도 없는 레이어를 건드리지 않아, PSD에서 켜 둔 옷·배경이 모든 배리에이션에 그대로 나왔다. 사용자 결정: "독립적으로 동작해야 함, PSD의 그것과 상관없이."
- "창 왼쪽에 현재 고른 조합에서 켜진 레이어가 미리 렌더되면 좋겠다. 렉이 걸릴 수 있으니 토글할 수 있으면 좋겠다."
- 카테고리 하나에 값이 없으면 배리에이션이 말없이 0개가 되고 내보내기 버튼이 꺼진다 (이슈 #1).

## 2. 결정 요약 (사용자 확인)

| 질문 | 결정 |
|---|---|
| 켜지는 레이어 | 지금 배리에이션과 일치하는 조합에 체크된 레이어 + 그 조상 그룹. 나머지 문서의 모든 레이어는 끈다 |
| 그룹을 체크하면 자식도 켜지나 | 아니다. 자식은 각자 체크해야 켜진다 |
| 하위 한꺼번에 넣기 | 그룹 체크박스 Ctrl+클릭 = 그룹과 모든 하위 레이어를 함께 넣고/뺀다 |
| 미리보기 위치 | 레이어 탭에서만, 왼쪽 그림 · 오른쪽 기존 목록. 경계를 끌어 너비 조절 |
| 미리보기 그리는 법 | 포토샵이 실제로 합쳐 그린 그림 (블렌드·클리핑·효과 그대로). 패널 합성은 안 함 |
| 렉 대책 | "패널 미리보기" 토글 (기본 꺼짐, 기억), 마지막 요청만 그리기, 같은 조합 캐시 |

## 3. 규칙 (core)

### 3.1 켜지는 레이어 (조합 spec §5.2 대체)

- `visibleLayerIds(combos, layers, variation)`: `onLayerIds(combos, variation)` 중 문서에 있는 레이어와, 그 레이어들의 조상 그룹 id 전부를 오름차순으로 돌려준다. 조상은 `layers[].parentId`를 따라 올라간다.
- 배리에이션의 on = `visibleLayerIds(...)`, off = 문서의 나머지 모든 레이어 id (그룹·배경 레이어 포함).
- 그룹이 체크돼 있어도 자식은 on에 들어가지 않는다. 자식이 하나도 체크되지 않은 그룹은 켜져도 빈 그림이다.
- `managedLayerIds`는 남겨 두되 내보내기·미리보기 경로에서는 더 쓰지 않는다.

### 3.2 내보내기 작업 목록 (조합 spec §5.7 변경)

- `buildJobs`의 on/off를 §3.1로 계산한다. 경로·충돌은 그대로.
- 경고:
  - `orphan`, `stale`: 기존과 같다.
  - `parentHidden`: 지운다. 부모 그룹은 §3.1에서 항상 켜지므로 더 생기지 않는다.
  - `unused` (새): 어느 조합에도 없고, 어느 조합 레이어의 조상도 아닌 레이어. 레이어마다가 아니라 경고 1개에 개수만 담는다 (`detail: { count }`). 문구 "어느 조합에도 체크되지 않은 레이어 N개는 출력되지 않음".

### 3.3 하위 포함 (Ctrl+클릭)

- `withDescendants(layers, ids)`: `ids`와 그중 그룹인 레이어의 모든 하위 레이어 id를 중복 없이 돌려준다.

### 3.4 배리에이션 0개의 이유 (이슈 #1)

- `emptyReasons(categories, include)` → `{ noValues: [categoryId], allFiltered: [categoryId] }`.
  - `noValues`: 값이 하나도 없는 카테고리.
  - `allFiltered`: 값은 있지만 "이번만 내보낼 값"에서 전부 꺼진 카테고리.
- 배리에이션이 0개인데 둘 다 비어 있으면 "항상 뺄 조합"이 전부 뺀 것이다.

## 4. 패널 UI

### 4.1 패널 크기 (조합 spec §6.1 변경)

- manifest 기본 크기를 너비 900 × 높이 760으로 바꾼다. 최소·최대는 그대로.

### 4.2 레이어 탭 배치

- 패널 미리보기가 켜져 있으면: 왼쪽 그림 영역 | 세로 경계(4px, 끌기) | 오른쪽 기존 내용(조합 고정 영역 + 트리).
  - 그림 영역 너비 기본 = 탭 너비의 40%. 끌어서 바꾸며, 최소 160px, 오른쪽이 최소 320px 남게 막는다. 비율을 `localStorage`(`lm.previewWidth`)에 기억한다 (읽기·쓰기는 try/catch, 실패하면 기본값).
  - 탭 너비가 600px 미만이면 위아래로 쌓는다: 위 그림(높이 40%, 최소 120px), 아래 기존 내용. 경계는 가로로 끈다.
- 꺼져 있으면 지금과 똑같이 기존 내용만 전체 너비로 그린다.

### 4.3 체크박스 Ctrl+클릭 (조합 spec §6.2 추가)

- 체크박스 클릭에 Ctrl(맥은 Cmd)이 눌려 있으면 대상 = `withDescendants(layers, 기존 대상)`. 기존 대상은 지금 규칙 그대로(클릭한 행이 선택돼 있으면 선택 전체, 아니면 그 행).
- 넣을지 뺄지는 지금처럼 클릭한 체크박스 상태로 정한다 (체크돼 있으면 전부 빼고, 아니면 전부 넣음).
- 점선(inherited) 체크박스는 Ctrl이 있어도 지금처럼 그 조합으로 이동한다.
- 행 클릭의 Ctrl(여러 개 선택)은 그대로다. 체크박스 위가 아닌 곳에서만 동작한다.
- 체크박스 title에 "Ctrl+클릭: 하위 레이어까지" 를 덧붙인다 (그룹 행만).

### 4.4 패널 미리보기

- 조합 고정 영역의 "포토샵 미리보기" 옆에 `패널 미리보기` 체크박스. 기본 꺼짐. `localStorage`(`lm.panelPreview`)에 기억한다.
- 그릴 배리에이션 = `previewVariation(LMState.combo, categories)` (포토샵 미리보기와 같음: 전체인 카테고리는 첫 값). null이면 그림 대신 "값이 없는 카테고리가 있어 미리보기를 할 수 없습니다".
- on/off = §3.1. 캐시 키 = on id 목록 문자열.
- 그림 영역 구성:
  - 이미지: 영역에 맞춰 비율 유지(contain), 투명 부분은 체커보드 배경.
  - 위쪽 작은 줄: 조합 이름(`comboName(variation)`) · `다시 그리기` 버튼.
  - 그리는 중이면 이미지 위에 "그리는 중…" (직전 그림은 흐리게 남겨 둔다).
  - 실패하면 이미지 자리에 오류 문구 (호스트 오류 코드는 §5.2).
- 다시 그리는 때:
  - 토글을 켤 때, 조합 선택이 바뀔 때, 체크박스로 조합이 바뀔 때. 캐시에 있으면 호스트를 부르지 않고 바로 보여 준다.
  - 새로고침 결과 레이어 구조 서명(레이어 id·parentId·순서)이 바뀌었으면 캐시를 비우고 지금 조합을 다시 그린다. 서명이 같으면(레이어 선택·눈 변경 등) 아무것도 안 한다. 눈 상태는 §3.1에서 결과에 영향이 없다.
  - `다시 그리기`: 지금 조합의 캐시를 버리고 그린다. 붓질처럼 포토샵이 이벤트를 보내지 않는 변경은 이것으로 반영한다.
- 마지막 요청만: 그리는 중에 새 요청이 오면 대기 칸 하나에 덮어쓴다. 지금 그리기가 끝나면 대기 칸 것만 그린다.
- 캐시: 메모리에 최근 20개(키 → 임시 파일 경로). 넘치면 오래된 것부터 목록에서만 버린다. 파일은 그대로 두고, 임시 폴더는 §5.2의 첫 호출 정리로 비운다.
- 내보내는 중에는 그리지 않는다. 끝나면 대기 요청이 있으면 그린다.
- 문서가 바뀌면 캐시를 비운다.

### 4.5 포토샵 미리보기 (조합 spec §6.3 변경)

- 반영 on/off를 §3.1로 계산한다. "건드린 레이어"는 문서의 모든 레이어가 된다. 켜기 전 스냅샷(전체 레이어)으로 끄면 원래대로 돌아오는 동작은 그대로.

### 4.6 내보내기 탭 (내보내기 spec §6 추가)

- `exportBegin`에 문서의 모든 레이어 id를 넘긴다 (끝나면 전체 눈 상태가 시작 전으로 돌아옴).
- 배리에이션이 0개면 개수 줄 아래 이유를 빨간 글씨로 (§3.4):
  - `값 없는 카테고리: 야스, 알주입`
  - `"이번만 내보낼 값"에서 모두 끈 카테고리: 옷`
  - 둘 다 없으면 `"항상 뺄 조합"이 모든 배리에이션을 뺐습니다`
- 경고 목록에 `unused` 문구 (§3.2). `parentHidden` 문구는 지운다.

## 5. 호스트 API (기존 spec §7 변경)

### 5.1 바뀌는 것

- `exportBegin({doc, layerIds})`: 받는 목록이 전체 레이어가 될 뿐 동작은 같다.
- `applyVisibility`, `exportOne`, `measureBounds`: 인자 형식 그대로. on/off 목록이 길어진다 (문서 전체).

### 5.2 `LM.renderPreview({doc, on, off, maxSize})` (새)

- `activateExpected(doc)` 후 활성 문서에서:
  1. 다시 실행(Redo)할 단계가 있으면(`activeHistoryState`가 마지막 history state가 아님) `LM_REDO_PENDING` 오류. 그리면 그 단계들이 사라지기 때문이다.
  2. `saved = doc.activeHistoryState`.
  3. `applyVisibilityAs('LayerMemorier preview', on, off)` (한 단계).
  4. `withMergedDuplicate`로 합친 복제본을 만들고, 긴 변이 `maxSize`(패널은 1024)보다 크면 비율 유지 축소(bicubic). 작으면 그대로.
  5. 복제본을 PNG-24(투명)로 `Folder.temp/LayerMemorier/preview_<시각ms>.png`에 저장 (`sfwPng24`). 8192px 제한은 축소 뒤라 걸리지 않는다.
  6. `finally`: `doc.activeHistoryState = saved` 로 3의 단계를 되돌린다. 복제본은 `withMergedDuplicate`가 닫는다.
- 반환 `{ path, width, height, ms }` (`ms` = 1~6에 걸린 시간, e2e에서 잰다).
- 처음 부를 때(호스트 로드 후 첫 호출) `Folder.temp/LayerMemorier/`의 `preview_*.png`를 지운다.
- 오류 코드: `LM_REDO_PENDING` → 패널 문구 "다시 실행할 단계가 있어 미리보기를 미룹니다 (작업을 하나 하거나 다시 그리기)". `LM_EMPTY`는 생기지 않는다 (빈 그림도 저장).
- 패널은 호출 전후로 `muteEcho()`를 부른다. 3·6이 일으키는 `Shw `/`Hd  `/`slct` 이벤트는 패널 자신의 메아리다.

## 6. 오류와 경계

- `renderPreview`가 실패해도 문서 가시성·히스토리는 6단계 `finally`로 원래대로 돌아온다. 되돌리기 자체가 실패하면 오류를 그대로 올린다 (패널에 표시).
- 패널 미리보기를 그리는 도중 사용자가 다른 문서 탭을 누르면 `activateExpected`가 원래 문서로 돌아와 그린다 (내보내기와 같은 방식).
- 포토샵 미리보기와 패널 미리보기를 같이 켜도 된다. 패널 미리보기는 그린 뒤 캔버스를 포토샵 미리보기 상태로 되돌린다 (6단계).

## 7. 검증

### 7.1 단위 (`npm test`, 맥에서도 돌아감)

- `visibleLayerIds`: 체크한 레이어 + 조상만 / 그룹만 체크하면 자식 제외 / 없는 레이어 무시 / 여러 조합 합집합.
- `buildJobs`: off = 문서 나머지 전부(체크 안 된 배경 포함) / `parentHidden` 없음 / `unused` 개수.
- `withDescendants`: 중첩 그룹 / 레이어만 주면 그대로 / 중복 제거.
- `emptyReasons`: 값 없는 카테고리 / 전부 꺼진 카테고리 / 둘 다 없음.

### 7.2 호스트 E2E (Windows + 포토샵, 사용자 실행)

- 같은 조합을 PSD 눈 상태를 바꿔 두 번 내보내면 결과 PNG가 바이트 단위로 같다.
- 내보내기 후 문서 전체 레이어의 눈 상태가 시작 전과 같다.
- `renderPreview` 후 history state 개수와 `activeHistoryState`, 레이어 눈 상태가 호출 전과 같다.
- Redo 단계가 있으면 `LM_REDO_PENDING`.
- 사용자 PSB(12000×13500)에서 `renderPreview`의 `ms`를 기록한다.

### 7.3 패널 E2E (`test/e2e/panel.test.js`)

- 그룹 체크박스 Ctrl+클릭 → 그룹과 하위 전체가 그 조합에 들어감, 다시 Ctrl+클릭 → 전부 빠짐.
- 패널 미리보기 켜기 → 이미지 표시, 조합 바꾸기 → 다른 이미지, 되돌리기 → 캐시에서 호스트 호출 없이 표시.
- 값 없는 카테고리 → 내보내기 탭에 `값 없는 카테고리:` 문구.

### 7.4 사용자 확인

- 실제 PSB에서 미리보기 속도가 쓸 만한지.
- 체크 안 한 레이어(배경 등)가 사라지는 것이 의도와 맞는지.

## 9. 범위 밖

- 패널에서 레이어 썸네일을 합성하는 빠른 미리보기 (블렌드·클리핑이 틀려서).
- 미리보기에 잘라내기·크기·여백 등 출력 옵션 반영 (전체 캔버스를 그대로 보여 줌).
- 기존 데이터 자동 변환 (그룹만 체크된 곳에 자식 체크를 채우는 것). 사용자가 Ctrl+클릭으로 직접 넣는다.
- 별도 미리보기 패널(두 번째 CEP 확장).
