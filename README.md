# LayerMemorier

포토샵 2020(21.0.2) CEP 패널. 레이어에 배리에이션 마크를 붙이고 모든 조합을 PNG로 내보낸다.

## 설치 (Windows)

1. **파일 받기.** `LayerMemorier.zip`을 받았다면 오른쪽 클릭 ▸ **압축 풀기**를 하고 2번으로 간다.
   저장소에 접근할 수 있다면 GitHub 페이지에서 초록색 **Code** 버튼 ▸ **Download ZIP**을 써도 된다.
2. **폴더 두기.** 압축을 풀면 `LayerMemorier` 또는 `LayerMemorier-main` 같은 이름의 폴더가 나온다. 이 폴더를 앞으로
   지우지 않을 자리에 둔다 (예: `D:\Tools\LayerMemorier`). **설치한 뒤에 이 폴더를 옮기거나 지우면
   패널이 안 뜬다.** 폴더 안에 `CSXS`, `client`, `install` 폴더가 보이면 제대로 된 위치다.
3. **설치 실행.** 그 폴더 안의 `install` 폴더를 열고, `install.ps1` 파일을 **오른쪽 클릭 ▸
   PowerShell에서 실행**을 고른다.
   - "이 스크립트를 실행하시겠습니까" 같은 경고가 나오면 `A`(모두 실행)를 누르고 Enter.
   - 검은 창에 `OK. Restart Photoshop...` 이 나오면 성공이다. 창이 그냥 깜빡이고 닫히거나
     빨간 글씨가 나오면 아래 "문제가 생기면"을 본다.
4. **포토샵 재시작.** 포토샵을 완전히 껐다 켜고 `창 ▸ 확장 ▸ LayerMemorier`를 연다.
   한 번 열어 두면 워크스페이스에 남아서 다음에 켤 때도 그대로 있다.

새 버전을 받으면 3~4번만 다시 하면 된다 (2번의 폴더 자리를 그대로 쓰는 경우 1~2번도 생략).

### 지우기

`install` 폴더의 `uninstall.ps1`을 같은 방식(오른쪽 클릭 ▸ PowerShell에서 실행)으로 실행한다.

> `%APPDATA%\Adobe\CEP\extensions\LayerMemorier`는 실제 폴더가 아니라 2번에서 둔 폴더를 가리키는
> **바로가기(정션)** 다. 탐색기에서 이 폴더를 직접 지우면 안에 든 것이 원본과 같이 보여서,
> 원본 폴더까지 같이 지워질 수 있다. 반드시 `uninstall.ps1`로 지운다.

## 사용법

1. PSD를 열고 패널의 **카테고리** 탭에서 카테고리와 값을 만든다. 자주 쓰는 구성은 "현재 구성을 프리셋으로 저장"으로 저장해 두고 다음 파일에서 "적용"한다.
   - 값마다 칸이 두 개다. 왼쪽 **값 이름**은 패널에서만 쓰고(레이어 탭 조합 선택에 뜬다), 오른쪽
     **파일명에 쓸 글자**가 실제로 파일명에 들어간다. 오른쪽을 따로 고치지 않으면 왼쪽을 따라간다.
   - 오른쪽 칸을 **비우면** 그 값일 때 파일명에서 그 부분이 통째로 빠진다 (예: 기본 상태).
   - 카테고리 이름 옆 드롭다운 = 값이 파일명에 들어갈 모양. `값만`(`1`), `이름+값`(`옷1`), `이름_값`(`옷_1`).
   - 카테고리 아래 초록색 줄에 지금 설정으로 파일명에 들어갈 글자가 그대로 보인다.
   - 순서는 ▲▼로 바꾼다. 파일명 순서 = 폴더 순서. 폴더로 묶을지는 내보내기 탭에서 정한다.
2. **레이어** 탭에서 조합마다 켜질 레이어를 정한다.
   - 위쪽 고정 영역에서 카테고리마다 값을 고른다. 상관없는 카테고리는 `전체`로 둔다.
     예: A=0, B=2, N=전체 → "A0_B2" 조합. N1·N2 모두에 적용된다.
   - 아래 트리에서 그 조합에 켜질 레이어의 체크박스를 누른다. 다시 누르면 뺀다.
     - 점선 칸은 더 넓은 조합(예: A0)에서 이미 켜진 레이어다. 누르면 그 조합으로 이동한다.
     - 행 오른쪽 흐린 글씨 = 그 레이어가 들어 있는 조합 전부.
   - 여러 레이어를 한 번에: 행을 Ctrl+클릭(하나씩)·Shift+클릭(범위)으로 고른 뒤 고른 행의 체크박스를 누르면 전부 들어간다.
   - **그룹 체크박스를 Ctrl+클릭**하면 그 그룹과 안의 모든 레이어가 함께 들어간다 (다시 Ctrl+클릭하면 함께 빠진다).
     그냥 클릭하면 그룹만 들어가고 안의 레이어는 각자 체크해야 켜진다.
   - "만든 조합"에서 지금까지 만든 조합으로 바로 이동한다.
   - **포토샵 미리보기**를 켜면 고른 조합이 캔버스에 바로 보인다. `전체`인 카테고리는 첫 값으로 보여 준다.
     끄면 원래 가시성으로 돌아온다. 켠 채로 패널을 닫으면 미리보기 상태가 그대로 남으니 끄고 닫는다.
   - **패널 미리보기**를 켜면 레이어 탭 왼쪽에 고른 조합이 내보낼 그림 그대로 그려진다 (블렌드·클리핑·효과 포함).
     - 큰 문서는 한 번 그리는 데 몇 초 걸릴 수 있다. 느리면 끄면 된다 (켜고 끈 상태는 기억된다).
     - 가운데 경계를 끌어 너비를 바꾼다. 패널이 600px보다 좁으면 그림이 위로 올라간다.
     - 한 번 그린 조합은 다시 고르면 바로 나온다. 붓질처럼 포토샵이 패널에 알리지 않는 변경은 **다시 그리기**로 반영한다.
     - 그리는 동안 문서는 바뀌지 않고 히스토리에도 남지 않는다. 단, Ctrl+Z 직후처럼 다시 실행할 단계가 남아 있으면
       그 단계를 지우지 않도록 그리지 않고 기다린다 (작업을 하나 하거나 다시 그리기).
   - **출력은 PSD의 눈 상태와 상관없이 조합 체크만으로 정해진다.** 켜지는 것은 그 조합에 체크된 레이어와 그 부모 그룹뿐이고,
     나머지는 전부 꺼진다. 배경·선화처럼 항상 나와야 하는 레이어는 모든 조합(전부 `전체`)에 체크한다.
   - 포토샵에서 지정한 레이어 색은 트리의 눈 칸 배경으로 보인다 (패널은 색을 바꾸지 않는다).
   - 조합은 PSD 파일 안에 저장된다. **PSD를 저장해야 남는다.** 0.1.x에서 마크한 PSD는 열면 자동으로 바뀐다.
3. **내보내기** 탭에서 출력명·출력 폴더를 정하고 미리보기를 확인한 뒤 "내보내기".
   - **폴더**: 체크한 카테고리마다 폴더 한 단계. 이름은 `누적`(예: `출산_기본의상_옷2`) 또는 `값만`(예: `옷2`).
     폴더 순서는 카테고리 순서와 같다 (카테고리 탭의 ▲▼).
   - **형식**: PNG-24, PNG-8, JPG, TIFF, TGA, BMP, PSD. 고른 형식의 옵션만 보인다.
     회색으로 막힌 칸은 지금 설정에서 의미가 없는 칸이다 (예: 투명도를 켠 PNG-24의 매트).
   - **크기**:
     - 잘라내기 `조합마다 각자` = 파일마다 투명한 가장자리를 잘라낸다 (크기가 제각각).
     - 잘라내기 `모든 조합 공통 영역` = 모든 파일의 크기·위치가 같다. "이번만 내보낼 값"으로 일부만 내보내도
       모든 조합의 영역을 먼저 재므로, 이전에 내보낸 파일과 크기·위치가 맞는다 (재는 시간이 더 걸림).
     - 크기 % 와 여백 px 은 잘라낸 뒤에 적용된다.
   - 접미사는 확장자 바로 앞에 붙는다. 대소문자는 폴더 이름에도 적용된다.
   - "기존 파일 덮어쓰기"를 끄면 같은 이름이 있을 때 `이름 (2).png`처럼 따로 저장한다.
   - 설정은 PSD 안에 저장된다. 설정이 없는 새 PSD는 마지막에 쓴 설정으로 시작한다.
   - **이번만 내보낼 값 (저장 안 됨)**: 일부 값만 체크하면 이번에 그 조합만 내보낸다.
   - **항상 뺄 조합 (PSD에 저장)**: 특정 값 조합을 영구히 뺀다.
   - 배리에이션이 0개면 이유가 빨간 글씨로 나온다 (값 없는 카테고리, 이번만 내보낼 값에서 모두 끈 카테고리 등).
   - 경고의 "체크되지 않은 레이어 N개"는 어느 조합에도 체크하지 않아 출력에 안 나오는 레이어 수다.
   - 끝나면 레이어 가시성은 시작 전 상태로 돌아온다. 원본 문서는 가시성 말고 바뀌지 않는다.
   - 저장에 실패한 파일은 기존 파일을 그대로 둔다. 내보내는 도중 다른 문서 탭을 눌러도 원래 문서로 돌아와 계속한다.

## 문제가 생기면

- 패널이 메뉴에 없다: `install.ps1`을 다시 실행하고(설치 3번) 포토샵을 재시작한다. 2번에서 둔 폴더를
  옮기거나 지웠다면 그것부터 되돌린다.
- 패널이 비어 있다: 문서를 열어야 내용이 보인다. 상단 "새로고침"을 누른다.
- 파일명이 겹친다고 나온다: 두 값의 "파일명에 쓸 글자"가 같다. 카테고리 탭에서 고친다.
- 어떤 레이어가 출력에 안 나온다: 그 레이어가 그 조합(또는 더 넓은 조합)에 체크돼 있지 않다. 0.4.0부터 체크하지 않은 레이어는
  PSD에서 켜져 있어도 꺼진다. 그룹만 체크하고 안의 레이어를 체크하지 않은 경우도 같다 → 그룹 체크박스를 Ctrl+클릭.
- 패널 미리보기가 안 바뀐다: **다시 그리기**를 누른다. "다시 실행할 단계가 있어"가 보이면 작업을 하나 한 뒤 다시 그리기.
- 개발자용 진단: `node tools/panel.js shot dbg` (패널 스크린샷), `npm run test:e2e`.

## 개발

- `npm test` — 단위 테스트 (core, 호스트·패널은 포토샵 없이 스텁으로)
- `sh tools/make-dist.sh` (mac/Linux) 또는 `tools/make-dist.ps1` (Windows) — `dist/LayerMemorier-<버전>.zip`
- `npm run test:e2e` — 포토샵을 COM으로 띄워 호스트·내보내기·패널 검증 (포토샵 2020 필요)
- `npm run panel:shot <label>` — 열려 있는 패널 스크린샷을 `test/out/shots/<label>.png`로 저장

## 인계

- 실제 프시케 포즈 PSD로 하는 리허설(Plans/20260915_LayerMemorier_spec.md §11.5)은 이번에 못 했다 — 개발 PC(`D:\Project\mezzakuzza`, 사용자 폴더, `C:\`·`D:\` 전체)를 뒤져도 프시케 포즈 PSD가 없었다. `mezzakuzza`에는 내보낸 PNG만 있고 원본 PSD는 없다. 아티스트가 실제 PSD로 여는 첫 시도가 사실상의 첫 리허설이 된다.
- 그때 같이 확인해야 할 것 (spec §11.5):
  - 레이어가 수백 개인 실제 문서에서 패널 반응 속도, 배지 글자가 읽히는지.
  - 내보낸 PNG의 색 공간·품질이 기존 파이프라인과 같은지.
- 레이어 수가 많은 문서에서 "새로고침"이 2초 넘게 걸리면: `client/ui`의 `LMApp.refresh()`가 매번 `getLayers`(ActionManager 전체 순회)를 다시 부르기 때문이다. `select` 이벤트 처리에서는 레이어 목록을 캐시해 두고 `getSelectedLayerIds`만 다시 읽도록 나누는 개선이 남아 있다.
