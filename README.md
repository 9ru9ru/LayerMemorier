# LayerMemorier

포토샵 2020(21.0.2) CEP 패널. 레이어에 배리에이션 마크를 붙이고 모든 조합을 PNG로 내보낸다.

## 설치 (Windows)

1. **파일 받기.** `LayerMemorier.zip`을 받았다면 오른쪽 클릭 ▸ **압축 풀기**를 하고 2번으로 간다.
   저장소에 접근할 수 있다면 GitHub 페이지에서 초록색 **Code** 버튼 ▸ **Download ZIP**을 써도 된다.
2. **폴더 두기.** 압축을 풀면 `LayerMemorier` 또는 `LayerMemorier-main` 같은 이름의 폴더가 나온다. 이 폴더를 앞으로
   지우지 않을 자리에 둔다 (예: `D:\Tools\LayerMemorier`). **설치한 뒤에 이 폴더를 옮기거나 지우면
   패널이 안 뜬다.** 폴더 안에 `CSXS`, `client`, `install` 폴더가 보이면 제대로 된 위치다.
3. **설치 실행.** 그 폴더 안의 `install` 폴더를 열고, `install.ps1` 파일을 **오른쪽 클릭 ▸
   PowerShell에서 실행**을 고른다.
   - "이 스크립트를 실행하시겠습니까" 같은 경고가 나오면 `A`(모두 실행)를 누르고 Enter.
   - 검은 창에 `OK. Restart Photoshop...` 이 나오면 성공이다. 창이 그냥 깜빡이고 닫히거나
     빨간 글씨가 나오면 아래 "문제가 생기면"을 본다.
4. **포토샵 재시작.** 포토샵을 완전히 껐다 켜고 `창 ▸ 확장 ▸ LayerMemorier`를 연다.
   한 번 열어 두면 워크스페이스에 남아서 다음에 켤 때도 그대로 있다.

새 버전을 받으면 3~4번만 다시 하면 된다 (2번의 폴더 자리를 그대로 쓰는 경우 1~2번도 생략).

### 지우기

`install` 폴더의 `uninstall.ps1`을 같은 방식(오른쪽 클릭 ▸ PowerShell에서 실행)으로 실행한다.

> `%APPDATA%\Adobe\CEP\extensions\LayerMemorier`는 실제 폴더가 아니라 2번에서 둔 폴더를 가리키는
> **바로가기(정션)** 다. 탐색기에서 이 폴더를 직접 지우면 안에 든 것이 원본과 같이 보여서,
> 원본 폴더까지 같이 지워질 수 있다. 반드시 `uninstall.ps1`로 지운다.

## 사용법

1. PSD를 열고 패널의 **카테고리** 탭에서 카테고리와 값을 만든다. 자주 쓰는 구성은 "현재 구성을 프리셋으로 저장"으로 저장해 두고 다음 파일에서 "적용"한다.
   - 값마다 칸이 두 개다. 왼쪽 **값 이름**은 패널에서만 쓰고(레이어 탭 체크박스에 뜬다), 오른쪽
     **파일명에 쓸 글자**가 실제로 파일명에 들어간다. 오른쪽을 따로 고치지 않으면 왼쪽을 따라간다.
   - 오른쪽 칸을 **비우면** 그 값일 때 파일명에서 그 부분이 통째로 빠진다 (예: 기본 상태).
   - 카테고리 이름 옆 드롭다운 = 값이 파일명에 들어갈 모양. `값만`(`1`), `이름+값`(`옷1`), `이름_값`(`옷_1`).
   - 카테고리 아래 초록색 줄에 지금 설정으로 파일명에 들어갈 글자가 그대로 보인다.
   - "폴더" 체크 = 그 카테고리 단계에서 폴더로 묶는다. 순서는 ▲▼로 바꾼다. 파일명 순서 = 폴더 순서.
2. **레이어** 탭에서 레이어를 고르고(포토샵에서 골라도 된다, Ctrl+클릭으로 여러 개) 값 체크박스를 켠다.
   - 마크 없는 레이어는 내보낼 때 건드리지 않는다. 마크가 있으면 조합에 맞을 때 켜고 아니면 끈다.
   - 그룹에 마크를 붙이면 그룹 전체가 그 규칙을 따른다.
   - 마크는 PSD 파일 안에 저장된다. **PSD를 저장해야 남는다.**
3. **내보내기** 탭에서 출력명·출력 폴더를 정하고 미리보기를 확인한 뒤 "내보내기".
   - 부분 출력: 일부 값만 체크하면 그 조합만 내보낸다 (저장되지 않음).
   - 제외 조합: 특정 값 조합을 영구히 뺀다 (저장됨).
   - 끝나면 레이어 가시성은 시작 전 상태로 돌아온다.

## 문제가 생기면

- 패널이 메뉴에 없다: `install.ps1`을 다시 실행하고(설치 3번) 포토샵을 재시작한다. 2번에서 둔 폴더를
  옮기거나 지웠다면 그것부터 되돌린다.
- 패널이 비어 있다: 문서를 열어야 내용이 보인다. 상단 "새로고침"을 누른다.
- 파일명이 겹친다고 나온다: 두 값의 "파일명에 쓸 글자"가 같다. 카테고리 탭에서 고친다.
- 어떤 레이어가 어느 조합에서도 안 나온다: 그 레이어의 부모 그룹이 마크 없이 꺼져 있다. 그룹을 켜거나 그룹에 마크를 붙인다.
- 개발자용 진단: `node tools/panel.js shot dbg` (패널 스크린샷), `npm run test:e2e`.

## 개발

- `npm test` — core 단위 테스트
- `npm run test:e2e` — 포토샵을 COM으로 띄워 호스트·내보내기·패널 검증 (포토샵 2020 필요)
- `npm run panel:shot <label>` — 열려 있는 패널 스크린샷을 `test/out/shots/<label>.png`로 저장

## 인계

- 실제 프시케 포즈 PSD로 하는 리허설(Plans/20260915_LayerMemorier_spec.md §11.5)은 이번에 못 했다 — 개발 PC(`D:\Project\mezzakuzza`, 사용자 폴더, `C:\`·`D:\` 전체)를 뒤져도 프시케 포즈 PSD가 없었다. `mezzakuzza`에는 내보낸 PNG만 있고 원본 PSD는 없다. 아티스트가 실제 PSD로 여는 첫 시도가 사실상의 첫 리허설이 된다.
- 그때 같이 확인해야 할 것 (spec §11.5):
  - 레이어가 수백 개인 실제 문서에서 패널 반응 속도, 배지 글자가 읽히는지.
  - 내보낸 PNG의 색 공간·품질이 기존 파이프라인과 같은지.
- 레이어 수가 많은 문서에서 "새로고침"이 2초 넘게 걸리면: `client/ui`의 `LMApp.refresh()`가 매번 `getLayers`(ActionManager 전체 순회)를 다시 부르기 때문이다. `select` 이벤트 처리에서는 레이어 목록을 캐시해 두고 `getSelectedLayerIds`만 다시 읽도록 나누는 개선이 남아 있다.
